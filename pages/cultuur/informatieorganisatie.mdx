# Informatieorganisatie

Kroescontrol documenteert alles wat je nodig hebt om je werk te doen. Publieke informatie staat op deze site, interne documentatie in een apart systeem.

## Waar staat wat

| Wat | Tool | Toegang |
|-----|------|---------|
| **Publieke docs** (deze site) | Nextra (Next.js) op GitHub | Iedereen |
| **Interne docs** | Nextra op GitHub (apart repo) | Kroescontrol medewerkers |
| **Code & projecten** | GitHub | Per project |
| **Mail, agenda, chat** | Google Workspace | Kroescontrol medewerkers |
| **HR & verlof** | HoorayHR | Kroescontrol medewerkers |
| **Wachtwoorden** | 1Password | Kroescontrol medewerkers |

## Structuur

De documentatie is opgesplitst in drie lagen:

- **Public** — wat je nu leest. Over Kroescontrol, werken bij ons, kantoor, cultuur. Bedoeld voor iedereen die KC overweegt als werkgever of partner.
- **Internal** — handleidingen, processen en richtlijnen voor medewerkers. Denk aan: onboarding, declaraties, tooling, contracten.
- **Operations** — operationele documentatie: finance, planning, klantbeheer. Alleen voor het managementteam.

We hanteren het principe **"open tenzij"**: documentatie is standaard publiek, tenzij er een goede reden is om het intern te houden — privacy, bedrijfsgevoelige informatie of interne processen.

## Bijdragen

Documentatie wordt bijgehouden via GitHub. Zie je iets dat niet klopt of ontbreekt? Maak een pull request of laat het weten aan je contactpersoon.
